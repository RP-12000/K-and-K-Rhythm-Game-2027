# K&K 地图格式（MAP_FORMAT）

本文写给关卡设计和将来的地图编辑器（map designer）。地图的每一层都是 `assets/maps/` 下的一个 JSON 文件，歌在哪、路怎么连、区域名和文案放哪、谁先解锁谁、剧情入口在哪，全部写在文件里，改文件就能改地图，不用改代码。读取在 `map/CaveData`，布局在 `map/MapWorld`，绘制在 `map/MapRenderer`。代码和本文不一致时以代码为准，并请同时修正本文。

文中的键名保持英文。

---

## 0. 速览

| 文件 | 作用 |
|---|---|
| `maps/index.json` | 列出所有层：`{"levels": ["hub", "singles", ...], "stories": "stories"}`。没列出的文件不会读。 |
| `maps/<id>.json` | 一层地图（航线页、单曲、主线、主线各章、所有曲目）。 |
| `maps/stories.json` | 剧情正文，按剧情 id 存。 |

- **坐标**：x 向右，y 向下（和效果图一样），单位是 1920×1080 画面的像素；缩放 1 时屏幕大约显示 1920×1080 的范围。可以用负数。
- **出错**：文件坏了或缺键不会崩溃，只在日志里记一行（标签 `CaveData`），缺的键用默认值。

## 1. 一层（level）

| 键 | 默认 | 说明 |
|---|---|---|
| `id` | 必填 | 层的 id，和文件名一致。`hub` 是主界面（洞口，从欢迎画面进来的第一层），`all` 是所有曲目（只能从主界面右下角的按钮进去）。 |
| `kind` | `route` | `hub` 主界面（不能缩放）、`route` 航线（单曲、主线的章节模式层）、`chapter` 章节、`grid` 所有曲目网格。 |
| `title` / `titleZh` | id 大写 / 空 | 层名，画在地面上（`titleAt`）。 |
| `numeral` | 空 | 章节编号，如 `"01"`；决定“第 N 层”的 N。 |
| `route` / `routeZh` | 同 title | 所属航线名（如 `MAIN` / `主线`）。 |
| `parent` | `title` | 上浮回到哪一层。上浮只有一种做法：在这一层捏合到全图后继续捏合（电脑上是滚轮缩小）；手机返回键、电脑的 Esc / PageUp 也会上浮。主界面（`hub`）从 2026-10-16 起不再上浮回欢迎画面（Kelvin：「进入游戏主界面后，不要再提供上浮选项」）。 |
| `storyParent` | 同 `parent` | 故事模式下上浮到哪一层（见下面的「主线的两种模式」）。主线各章写这个：第一章写 `hub`，第二章写 `main_c1`，以此类推；`parent` 写章节模式层 `main`。 |
| `start` | 第一个点 | 镜头起点和“唤醒光”扩散的起点（一个点的 `id`）。 |
| `demo` | false | 演示数据标记。2026-10-16 起左上角不再显示 DEMO 标签，目前不影响画面。 |
| `collect` | false | 收留新歌：曲库里没有放到任何一层的歌，自动排在这层 `start` 点四周的空位上（2026-10-17 16:46 起；以前是排在最右边、三首一列）。空位是以 `start` 为中心的六边形格点（左右相邻 540，上下一排 380，和单曲层自己的排法一样），离中心近的先排（上下的距离按 4/3 倍算，也就是按 4:3 平板的比例，先把平板一屏排满再往外排），一样近时从右边开始逆时针；离本层任何点或已经排进来的歌不到 300 的格点不用。现在只有单曲层打开。 |
| `price` | 300 | 只对 `collect` 层有用：主线、支线（`hub`、`grid` 和 `collect` 层以外的层）都没有放的歌要先用贝壳买（2026-10-17），这是这层歌的默认价格。 |
| `depth` | 30 | 这层的海水深度（米）：越深背景越暗。 |
| `titleAt` | 无 | 层名牌的位置 `[x, y]`；不写就不画。 |
| `sub` / `subZh` | 空 | 层名下面的一行字。2026-10-16 起不再显示（Kelvin：标题下面的信息去掉）。点的 `sub` 照常显示，`@progress` = 本层歌曲数和通关数，`@charts` = 曲库歌曲数和谱面数。 |
| `overviewZoom` | 自动 | 全图（捏合到最小）时的缩放；不写就按地图大小自动算。 |
| `pools` | 无 | 地面光斑 `[[x, y, 半径, 强度0~1], ...]`。 |
| `spots` | 无 | 地图上的点，见 §2。 |
| `links` | 无 | 点之间的路，见 §3。 |
| `areas` | 无 | 区域名，见 §4。 |
| `signs` | 无 | 屏幕边缘的路牌，见 §4。 |
| `texts` | 无 | 自由文案位，见 §4。 |
| `packs` | 无 | 只用于 `grid`：曲包分组，见 §5。 |

**主线的两种模式**（Kelvin 2026-10-16）：主界面的 MAIN 点写 `"to": "main"`（章节模式层，所有章节和支线入口都在这一层）和 `"storyTo": "main_c1"`（故事模式直接进第一章）。故事模式是默认；章节模式层上所有没封住的竖井（章节和支线入口）都解锁以后，主界面设置按钮左边才出现「故事模式 / 章节模式」切换按钮，选的模式存在存档里（`mainChapterMode`）。上浮时：章节模式按 `parent`，故事模式按 `storyParent`（没写就按 `parent`）。封住（`sealed`）的竖井是还没做的章节，不算在“全部解锁”里。

## 2. 点（spots）

每个点：`{"id": "song1", "type": "song", "x": 740, "y": 700, ...}`

| `type` | 是什么 | 点击后 |
|---|---|---|
| `song`（默认） | 歌曲洞，`song` 写歌曲 id（`Charts/` 下的文件夹名） | 选中并打开歌曲卡 |
| `story` | 剧情入口，`story` 写剧情 id | 打开剧情卡；读完记为已读 |
| `shaft` | 竖井，`to` 写下一层的 id | 下坠到那一层（X3） |
| `route` | 航线洞口（航线页用），`to` 写目标层 | 旋涡进入那一层（X1） |
| `rise` | 上浮点。2026-10-16 起不画、不能点（上浮只靠捏合，见 §1 `parent`）；它的位置仍算进镜头范围，`start` 写它时镜头从这里开始 | 无 |
| `contact` | 未知信号（问号） | 只提示“敬请期待” |
| `tutorial` | 教程洞 | 开始新手教程 |

其他键：

| 键 | 说明 |
|---|---|
| `r` | 半径。默认：歌 108、剧情 76、竖井 156、航线 132、上浮 70、信号 34。 |
| `label` / `labelZh` / `sub` / `subZh` | 点下面的字（歌曲洞自动用歌名和定数，不用写）。`sub` 也可以用 `@progress` / `@charts`。 |
| `sealed` | true = 封住（铁栅栏和红灯），点了提示“未开放 · 敬请期待”。 |
| `requires` | 解锁条件：`["song3", "song4"]`，写本层点的 id 或歌曲 id，全部通关后才解锁。没通关时显示金锁和金色虚线指向要先通关的点。 |
| `storyTo` | 竖井和航线洞口：故事模式下去哪一层（不写就和 `to` 一样）。见 §1「主线的两种模式」。 |
| `at` | 竖井和航线洞口：进入目标层时镜头停在目标层的哪个点（点的 `id`），不写就停在目标层的 `start`。例：章节模式层的支线入口写 `"to": "main_c1", "at": "song4"`。从下面上浮回来时，镜头落在当初下去的那个入口。 |
| `secret` | 歌曲洞：特殊解锁的歌。`"hidden"` = 完全不出现（这一层和所有曲目里都没有）；`"glitch"` = 显示成雪花圆盘加乱码字，点了只闪一下，不开歌曲卡。存档里有 `reveal:<歌曲 id>` 这个标记后变回普通的歌（解锁流程以后由剧情或活动来设）。 |
| `area` | 所属区域 id（只用于整理，不影响显示）。 |
| `price` | 歌曲洞，只在 `collect` 层里有用：这首歌的价格（贝壳），比层的 `price` 优先。主线、支线里放了的歌不用买，写了也不管。 |
| `art` | 航线洞口的图：`songs`（一圈曲绘）、`shaft`（暗井，和主线一样的空洞；封住时罩上铁栅栏）；不写或写别的值 = 中间一张曲绘、周围六张。主界面的联动 2026-10-18 起是封住的 `shaft`（Kelvin：暂时不放曲绘）。 |
| `color` | 点的主色，如 `"#6FA8FF"`。 |

**通关的定义**：歌曲任意难度玩过一次；剧情读过；竖井和航线没封住；上浮洞永远算通关。一首歌在多层出现时各层分别显示，成绩共用。

## 3. 路（links）

`["a", "b", "kind", "area"]`，或写成 `{"a": "...", "b": "...", "kind": "...", "area": "..."}`。

| `kind` | 样子 |
|---|---|
| `main` | 主路：带箭头的虚线，两端都通关后变实线。 |
| `side` | 支路：同上，颜色跟区域。 |
| `path` | 普通路，不带箭头。 |
| `clue` | 线索：细的点线，只表示两处有关联。 |

路自动画成略弯的曲线；解锁条件的金色虚线不用写在 links 里，由 `requires` 自动生成。

## 4. 区域名、路牌、文案位

- `areas`：`{"id", "name", "nameZh", "sub", "x", "y", "color"}`，大字写在地面上；全图时更清楚。
- `signs`：`{"x", "y", "label", "labelZh", "sub", "color"}`，目标点在屏幕外时，在屏幕边缘显示一个带箭头的路牌，最多 12 个。
- `texts`：`{"x", "y", "text", "textZh", "size", "color"}`，地面上的一段自由文案（默认字号 22）。

## 5. 所有曲目（grid）

`packs`：`{"title", "titleZh", "songs", "placeholders", "note", "noteZh", "secret"}`。`songs` 写歌曲 id 列表，写 `"all"` 表示全部，不写就没有歌（只放空位）；`placeholders` 是“敬请期待”空位个数。第一个曲包排在左边，其余的排在右边一列。`secret`（特殊解锁的整章）：`"hidden"` = 这个曲包整组不出现，`"glitch"` = 曲包名变成乱码；两种情况下它用 id 列出的歌在所有曲目里都按同样方式隐藏或变乱码（存档标记 `reveal:pack:<title>` 解开）。

**锁**：一首歌在地图上出现的每个地方都还锁着时（`requires` 没满足），所有曲目里也显示金锁。点它照样打开歌曲卡，能看难度和定数，但 AUTO 是灰的，DESCEND 的位置写解锁条件（「先通关 X」）；有多个条件时每个停 3 秒，再用 1 秒淡出淡入换下一个。只要有一个地方是开的（比如单曲层里没有条件），所有曲目里就是开的；没放在任何一层的歌（单曲层自动收留）也是开的。

**要买的歌**（2026-10-17）：只在单曲层（`collect`）出现、主线和支线都没有的歌要先买（现在是 Aleph-0）。没买时地图上和所有曲目里洞里是贝壳图标、名字下面写价格；卡片里 DESCEND 的位置是「HOLD TO BUY」，按住 0.6 秒买下。价格先看歌曲洞的 `price`，再看 `collect` 层的 `price`，都没写是 300。买过的歌记在存档 `ownedSongs`；旧存档里玩过的歌都算买过。

**SORT**：右下角的 SORT 按钮打开排序面板：分组选按曲包或全部铺开，顺序选默认、歌名、定数、最高分、最近游玩，筛选选 NEW（没玩过）/ FULL COMBO / ALL RESONANCE（三选一，按当前难度算，再点一下取消；2026-10-16 从右上角的漏斗并进来）。有筛选生效时 SORT 按钮亮着并带一个小点。不符合的歌不排进网格，筛选时空位和曲包说明也不显示，特殊解锁的歌也不显示，一首都没有时显示「没有符合的歌」。

## 6. 剧情（stories.json）

```json
{"story01": {"number": "01", "title": "TITLE TBD", "titleZh": "标题待定", "minutes": 2,
             "pages": ["第一页英文", "第二页英文"], "pagesZh": ["第一页中文", "第二页中文"]}}
```

语言是中文时用 `pagesZh`，没有就用 `pages`。读过的剧情记在存档里（`story:<id>`）。

## 7. 加一层的步骤

1. 在 `assets/maps/` 新建 `<id>.json`，写好 `id`、`kind`、`parent`、`start` 和 `spots`。
2. 把 id 加进 `maps/index.json` 的 `levels`。
3. 在上一层放一个 `shaft`（或主界面放一个 `route`），`to` 写新层的 id。主线的新章节：在章节模式层 `main` 放一个竖井，并在上一章放一个竖井通往它；新章写 `"parent": "main"` 和 `"storyParent": "<上一章>"`。
4. 写好新层的 `parent`：玩家在新层捏合到全图后继续捏合就上浮回去（`rise` 点不再画出来，可以不放）；从下一层上浮回来时，镜头会落在 `to` 指向那一层的点上。
