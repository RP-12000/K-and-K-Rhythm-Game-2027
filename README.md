# K & K（Kelvinizer and Kathlina）

一款以“下潜”为主题的双判定线节奏游戏，用 [libGDX](https://libgdx.com/) 写成，支持桌面（Windows / macOS / Linux）和 Android。

当前版本 **0.2.0**（内测版，2026-11-07）。每一次改了什么见 `docs/CHANGES.md`（开发日志）。

> 这是一个男孩和一个女孩的故事，他们被困在一个黑暗的世界里。
> 唯一的出路，是向未知的更深处下潜。
> 并揭开他们最深的秘密，和那个悲剧的真相。
> 
> ——教程开场

## 1. 游戏是什么

* Kelvinizer 和 Kathlina 两个人一路向深处下潜。选歌界面是一张**洞穴地图**：开始画面之后先到洞口（CAVE MOUTH），从这里进 SINGLES 单曲、MAIN 主线和 COLLAB 联动（敬请期待）；洞口右下角是 ALL SONGS 所有曲目。主线一章是一层：现在有 01 SHORELINE 浅滩和 02 TWILIGHT 暮光层，03–07 章还封着。每首歌是地图上的一个洞；双指按住不动 1.5 秒上浮回上一层。
* 第一次启动先做三步首次设置，然后自动进新手教程；以后在 设置 → 其他 → 新手教程 重玩。
* 游戏画面有**两条判定线**：音符沿着轨道**落到下面的地面线**，或者**升到上面的天空线**。每条轨道是三维空间里一根单独的柱子，可以移动、转向、变大变小、淡入淡出，几条轨道还能收进一个**组**里一起动，镜头也能转；默认视角带一点 3D（看得到柱子的侧面和键的厚度）。另外还有**海面**，上面可以放不在轨道上的键。谱面编辑器现在存的是**谱面版本 2.1**（`docs/CHART_FORMAT.md` §9；文件里写 `"format": "2.1"`，和谱面编辑器的版本号一样，代码里都叫 v7），以后格式每改一次加 0.1；旧格式的谱照样能玩，8 条轨道的旧谱还是平面画面。
* **整列判定**：点音符所在的那一列就算，上下哪里都行；3D 画面里按在轨道柱子在屏幕上占的那块地方就算，按在几条轨道重叠的地方，这几条轨道里同一拍的键一起判；同一条轨道里同一拍天地两个键，按一下两个都判。谱面里标了**全屏判定**的段落，按屏幕任何地方都判最早的音符：段落开始前 1 拍两个箭头向外分开，结束前 1 拍两个箭头向内合拢。水雷不受这些影响：只有按在水雷上才算碰到。
* 九种音符和水雷轨道（谱面里的类型先写谱面版本 2.x 的，括号里是旧格式的）：

| 音符                    | 谱面里的类型                     | 怎么打                                                                 |
| --------------------- | -------------------------- | ------------------------------------------------------------------- |
| DROP 水滴               | `tap`                      | 到线上时点一下                                                             |
| STREAM 水流             | `stream`（`hold`）           | 按住，同一根手指按到结尾                                                        |
| MINE 水雷               | `mine`                     | 到线上时别按它；按到会断连击                                                      |
| LANE MINE 轨道水雷        | `streamMine`（`mine` 有时长）   | 变红的时候别碰这条轨道                                                         |
| TIDE 浪花               | `wave`（`universal`）        | 屏幕上任意位置点一下；可以横跨几条轨道或几片海面                                            |
| TIDE STREAM 潮汐        | `tide`（`universal` 有时长）    | 一直有手指按在屏幕上就算，可以换手指                                                  |
| TIDE MINE 浪花水雷        | `waveMine`（`tideMine`）     | 红色的浪花：到线上时别在这条线的判定区里按下                                              |
| TIDE STREAM MINE 潮汐水雷 | `tideMine`（`tideMine` 有时长） | 红色的潮汐：整段都别碰这条线的判定区                                                  |
| 水雷轨道（红色轨道）            | 轨道的 `m`（谱面版本 2.1）          | 整条轨道变红：落在上面的键只能打出 RESONANCE（强制严判，早了晚了都不算）；按到没键的地方什么都不发生（不扣分、不断连击、不报 LOST） |
| DRAG                  | `drag`                     | 不用点：在自己那条轨道上（海面上的按横坐标），到线上时手指在它那里（提前放着、滑过去都行）就是 RESONANCE，不在就是 LOST |

* 同一时刻要一起打的音符默认带一圈光晕（设置 → 视觉 → 游戏界面 → 多押辅助：可以关掉，或者再加上金色珍珠；水雷上是红色珍珠，提醒别碰）。有的音符后面拖着一串**残影**：残影只是光，不用打。
* 有的谱面里有**漩涡**（圆形或多边形的一片水，会动、会转）：在漩涡里按下的手指，抬起来之前什么都打不到，但不会断连击。
* **判定**：RESONANCE（±66.67 ms）、ECHO（±133.33 ms）、LOST；RESONANCE 里 ±33.33 ms 以内的另计为 PERFECT。偏早或偏晚会显示 EARLY / LATE。
* **分数**：准度分满分 100,000,000（RESONANCE 算 1 个，ECHO 算 0.55 个），加上共鸣链（最长的一段连续 RESONANCE，满了是 10,000）和每个 PERFECT 1 分，所以全部 PERFECT 是 100,010,000 加音符数。分数**显示成负数**，越深越好（比如 -98,765,432）。每碰到一个水雷，分数往 0 靠近 10,000（每个水雷只算一次）；开头还没得分时碰到水雷，分数会变成正数。详细规则见 `docs/CHANGES.md` §3 和 §7.162–7.164。
* **结果和评级**：打完就是 CLEAR；没有 LOST、也没有碰到任何水雷是 FULL COMBO；FULL COMBO 并且全部 RESONANCE 是 ALL RESONANCE（卡片上写 RESONATED）。评级按分数分 15 档：F、D、D+ … SS+、R（1 亿分及以上），全部 PERFECT 是 R+。
* **贝壳、珍珠和深度**：每局得贝壳；单曲里现在只有 My Soul 要用 300 贝壳买下，其他都免费（玩过的歌不用再买）。珍珠数先只显示。每张谱面按定数和分数算出一个深度，最深的 10 张平均就是玩家的深度（显示带负号，比如 -2,412 m）。头像坐在深度徽章（六边形）上，徽章按深度分 16 档，越深越华丽；头像现在只有一个默认的。

## 3. 用 IntelliJ IDEA 打开和运行（桌面版）

1. **打开工程**：File → Open，选仓库根目录（有 `settings.gradle` 的文件夹），作为 Gradle 工程打开并信任它。
2. **选 JDK 21**：File → Project Structure → Project → SDK 选 JDK 21；Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JVM 也选这个 JDK 21。语言级别不用改，Gradle 会按 Java 11 编译。
3. **等 Gradle 同步完成**。
   * 如果因为 `android` 模块同步失败（例如提示找不到 Android SDK）：安装 Android SDK，然后在仓库根目录建 `local.properties`，写一行 `sdk.dir=<Android SDK 的路径>`（这个文件不进 git），或者设置环境变量 `ANDROID_HOME`。
   * 只想跑桌面版的话，也可以临时把 `settings.gradle` 最后一行里的 `'android'` 删掉再同步。**这个改动不要提交。**
4. **运行**：打开右侧的 Gradle 工具窗口，双击 `lwjgl3` → Tasks → application → `run`。
   * 命令行也一样：`./gradlew lwjgl3:run`（Windows：`gradlew.bat lwjgl3:run`）。
   * 这个任务会把工作目录设成 `assets/`，加上需要的 JVM 参数，并且每次运行前更新资源清单 `assets/assets.txt`。
5. **另一种运行方式**：新建一个 Application 运行配置：
   * 模块（classpath）：`lwjgl3` 的 main（名字形如 `<文件夹名>.lwjgl3.main`）。
   * 主类：`org.kelvinizer.lwjgl3.Lwjgl3Launcher`。
   * 工作目录：`<仓库>/assets`。
   * macOS 不用手动加 `-XstartOnFirstThread`：启动器会自己用这个参数重新启动 JVM（`lwjgl3/src/main/java/org/kelvinizer/lwjgl3/StartupHelper.java`）。

窗口默认 1280 × 720，可以拉伸（最小 960 × 540）。

**打包成 jar**：`./gradlew lwjgl3:jar`，生成 `lwjgl3/build/libs/KandK-0.2.0.jar`，资源都打在 jar 里，用 `java -jar` 运行。另外还有 `lwjgl3:jarMac`、`lwjgl3:jarLinux`、`lwjgl3:jarWin`，只包含对应系统的本地库。打包前先把音乐文件放好，否则 jar 里没有音乐。

**版本号**：三处保持一致，改版本时一起改：`gradle.properties` 的 `projectVersion`、`android/build.gradle` 的 `versionName`（`versionCode` 每次发布加 1）、`core/.../Params.java` 的 `VERSION`（游戏里 设置 → 其他 最下面和开始画面显示的就是它）。

### Android

* Android 部分是 `android` 模块（启动器 `android/src/main/java/org/kelvinizer/android/AndroidLauncher.java`，资源直接用根目录的 `assets/`）。在 IntelliJ IDEA（需要 Android 插件）或 Android Studio 里打开同一个工程，选 `android` 模块的运行配置，连上手机或模拟器运行。
* 命令行：`./gradlew android:installDebug` 安装到连着的设备；`./gradlew android:run` 在设备上启动已安装的游戏（它按 `local.properties` 的 `sdk.dir` 或环境变量 `ANDROID_SDK_ROOT` 找 `adb`）。
* **更新时直接 `installDebug` 覆盖安装，不要先卸载**：卸载会把手机上的存档一起删掉。
* 游戏固定横屏（可以 180° 翻转），全屏沉浸模式；振动反馈需要的 `VIBRATE` 权限已经在 `android/AndroidManifest.xml` 里声明。

## 4. 键盘操作（桌面版）（已弃用）

鼠标左键相当于一根手指的触摸。键盘按键对应轨道（轨道编号见 `docs/CHART_FORMAT_v4.md` §3）：

| 判定线    | 左边轨道 −5 −4 −3 −2 −1 | 0 号轨道 | 右边轨道 1 2 3 4 5 |
| ------ | ------------------- | ----- | -------------- |
| 天空线（上） | Tab　Q　W　E　R         | T 或 Y | U　I　O　P　[      |
| 地面线（下） | CapsLock　A　S　D　F    | G 或 H | J　K　L　;　'      |

* **空格**：只判定地面线的 TIDE。另外，每一行的任何一个键也能判定**本条线**的 TIDE。
* 按键按**轨道 id** 对应。旧谱默认 8 条轨道（±1 到 ±4），用不到 CapsLock、'、Tab、[。0 号轨道只在谱面插入它时才有；没有 0 号轨道时 G / H / T / Y 只判定 TIDE。原版歌曲的谱面（v1）有 ±5 两条外侧轨道，平时在画面外，只在部分段落窗口收窄时进入画面。谱面版本 2.0 起，轨道 id 由谱面自己定，id 不在 −5 到 5 之间的轨道没有按键，只能用鼠标点。键盘不管全屏判定段落：每个键只判自己那条轨道。
* **暂停**：Esc 或键盘上的 Pause 键，立即暂停。暂停时按 Esc 或 Enter 继续（3-2-1 倒计时）。**P 是轨道键，不是暂停。**
* 触摸 / 鼠标暂停：默认是双击右上角的暂停键（设置 → 游玩 → 暂停方式 可以改成按住或单击）。
* 选歌地图：Esc 或 PageUp 上浮回上一层；滚轮缩放（所有曲目页是上下滚动）。

## 5. 歌曲和音乐文件放在哪里

* 曲库在 `assets/Charts/`：每首歌一个文件夹，**文件夹名就是歌曲 id**（也是存档里的键，不要改名）。里面是谱面（`Shallow.json`、`Medium.json`、`Deep.json`、`Abyss.json`，有几个放几个；旧命名 `Surface.json` 等也认）、曲绘图片和音乐。
* 章节、歌曲顺序和教程文件夹写在 `assets/Charts/index.json`；每张地图上哪首歌在哪里写在 `assets/maps/*.json`（见 `docs/MAP_FORMAT.md`）。没放进任何地图的歌会自动排进单曲层的空位。
* 教程在 `assets/Introduction/`（谱面 `Shallow.json`，旧命名 `Surface.json`；音乐 `Introduction.wav`）。
* **音乐文件不在 git 仓库里**（`.gitignore` 排除了下面这些位置的 `.mp3`、`.ogg`、`.wav`），拿到后按下面的路径放好：

| 音乐   | 放在                                                                       |
| ---- | ------------------------------------------------------------------------ |
| 每首歌  | `assets/Charts/<歌曲 id>/<歌曲 id>.mp3`，比如 `assets/Charts/Song 1/Song 1.mp3` |
| 教程   | `assets/Introduction/Introduction.wav`                                   |
| 菜单音乐 | `assets/background.wav`                                                  |

* 文件名要和文件夹名一样；扩展名 `.mp3`、`.ogg`、`.wav` 都可以（菜单音乐也一样）。缺少某个文件时，游戏照样能运行，只是对应的歌曲、教程或菜单没有声音。
* 加一首新歌、加章节的完整步骤见 `docs/ASSET_SLOTS.md` §5–§6 和 `docs/DEVELOPER.md` §6。
* 存档：桌面版在用户主目录的 `KandKGame/profiles/`（导出的备份在 `KandKGame/export/`）；Android 在应用自己的存储里。

## 7. 测试清单（0.2.0）

按画面排，写的是 0.2.0 应有的样子。每次更新后挑改到的部分测；中文和 EN 最好各看一遍（设置 → 其他 → 语言）。手机更新用 `installDebug` 覆盖安装，不要先卸载。

### 7.1 开始画面和首次设置

- [ ] 开始画面：大字 K & K，下面 `TWO SIGNALS · ONE DESCENT`（中文 两道信号 · 一同下潜），最底下 `TAP ANYWHERE TO START` / `点击任意位置开始`；点屏幕任意位置（K 字母和左下角玩家标签除外）开始。右下角没有设置齿轮。
- [ ] 左下角玩家标签：列出各个玩家和 `+ 新建玩家`（满 12 个时没有），玩家多时可以滚动，点一行切换玩家。
- [ ] 第一次启动（想重来可以先把 `KandKGame/profiles/` 改个名字，改回原名就能恢复存档）：首次设置三步，右上角写「第 1 步，共 3 步」，卡片在屏幕正中，没有返回键（手机的返回键能回上一步）。
  1. 舒适度（COMFORT），示例字 `SIGNAL`。
  2. 延迟校准：4 下预备拍再响 12 下，跟着点；结果「+40 ms」数字和单位一起居中；散点条两头是 −300 和 +300 ms，±150 以内占大部分宽度，外面两段的点是灰色空心圈。「应用」或「跳过」都进下一步。
  3. 目押校准：按键在卡片里落到线上，按平时的习惯点；结果是「-32 px」这样的 px 值，散点图写「线下方」「线上方」，没有 ms。「应用」或「跳过」后进教程。
- [ ] 新玩家的名字是 `DIVER-XXXX`，头像随机，都可以在个人页改。
- [ ] 手机上三步的卡片都完整放得下，不和底下的按钮重叠。

### 7.2 新手教程

- [ ] 首次设置做完自动开始；以后从 设置 → 其他 → 新手教程 重玩，结算画面的「再玩一次」也行。地图上没有教程的洞。
- [ ] 开场 `WELCOME TO`、`Kelvinizer and Kathlina` 和三行故事；然后介绍四个角，暂停那句跟着 设置 → 游玩 → 暂停方式（双击是默认，只有双击模式会播放双击演示，演示不会真的暂停）；再介绍 RESONANCE / ECHO / LOST 和 EARLY / LATE。
- [ ] 每一课都能打：地面 DROP、天空 DROP、TIDE、STREAM、TIDE STREAM、MINE（被碰到时红色 LOST 出现在水雷上方）、LANE MINE（「浪花当判定线」那一课 2026-11-06 起不在教程里，那几拍是普通水滴）。字幕放在当时没有音符经过的地方。
- [ ] 浪花当判定线那一课以后的对白现在是空的占位（等新文案），也不画空底板；结尾是 K & K，中间的 & 看得到，连击数在它出来时让开。
- [ ] `HOLD TO SKIP`（中文模式也是英文）在下判定线下面那条的正中，按住 0.6 秒跳过；第一次玩 10 秒后才出现，重玩时一开始就有；在 3-2-1 倒计时中跳过也直接进结算，歌不会在后面接着放。

### 7.3 选歌地图

- [ ] 洞口（CAVE MOUTH）：SINGLES、MAIN 和罩着铁栅栏的 COLLAB（敬请期待）；右下角 ALL SONGS。SINGLES 牌子上的「N SONGS」只数单曲地图上的歌，不是整个曲库；后面的「x/y CLEARED」只数地图上选中的那个难度的谱面（不写难度名）。名字下面的进度条也只算这个难度：全 RESONANCE 浅蓝实心、FULL COMBO 紫色斜纹、玩过的白色半透明。MAIN 下面也有进度条和「N SONGS · x/y CLEARED」，数主线每一章的歌（同一首只算一次）。
- [ ] 左上角深度徽章：头像坐在深度六边形上，六边形按深度分 16 档，里面写深度；名字默认收起，点头像展开或收起名字条，每次启动第一次进地图时名字条露 2 秒。六边形下面左边贝壳、右边珍珠，超过 9,999 显示 9,999+ 加一圈高光，点它弹出确切的数。右上角是设置键，它左边的玩家按钮进个人页。
- [ ] 进每一层都是最近的缩放，层名在最上面，字小、半透明。单曲的六首排成六边形；主线 01、02 章有歌和剧情（书本），03–07 章封着。第 1 章里通往第 2 章的竖井下面也有那一章的进度条和「N SONGS · x/y CLEARED」。
- [ ] 两根手指按住不动：0.3 秒后两指中间出现一个圈，1.5 秒转满就上浮一层（圈里写 RISE / 上浮）；手指一动就取消，照常缩放。缩到最小不会上浮；电脑上 Esc / PageUp 上浮。
- [ ] 每个洞外面是四圈分数环（最里圈 SHALLOW，最外圈 ABYSS）；拉近后，当前难度没打过的谱面显示青色 NEW。全连的评级是紫色，R / R+ 浅蓝带一道白光。
- [ ] 停在一首歌上开始试听：默认从整首歌的 30 % 放 20 秒，然后从头循环。歌曲文件夹里的 `song.json` 写了 `previewStartMs` / `previewEndMs` 时按它放；起点小于 0 时先静音再从歌曲开头放，终点超过音乐结尾时放完静音、等到终点，不跳回开头。
- [ ] 歌名里的希腊字母和日文都显示完整，例如 `Mγ ς0μ1(feat.初音ミク)` 的 ς。
- [ ] 歌曲文件夹的 `song.json` 有 `jacket16x9` / `jacketCircle`（谱面编辑器的曲绘取景）时：歌曲卡片和结算显示选的 16:9 那块，地图圆孔、转场圆盘和个人页小图显示选的圆形那块；没有时和以前一样取中间。
- [ ] 点歌打开右边的歌曲卡片：‹ › 换歌，深度写成「-4,000 / -5,760 m」，DESCEND 上面那一行是 NEXT 推分建议、MAX 或 MAXED；点地图空白处、往右划或按返回键（电脑上 Esc）关上。AUTO 打开后按钮变成 WATCH（自动演奏，不记成绩）。
- [ ] 单曲：没有解锁条件；Aleph-0 在主线里，不在单曲地图上。现在只有 My Soul 要买，另外五首免费；已经玩过的歌不用再买。
- [ ] 没买的单曲有金色虚线圈，洞里是贝壳、名字下面写 300；卡片底下一整行是金色的「按住购买 🐚 300」（AUTO 不显示），贝壳不够时变成灰色的「还差」；买下以后回到 AUTO + DESCEND。
- [ ] 所有曲目：一排两首、相邻两行错开半格，连成网（两头都打过是实线，否则虚线）；不缩放，上下拖动；右下 SORT 排序；右边的卡片一直开着；往下拖时歌从左上角徽章和设置键底下过去。
- [ ] 英文模式下地图上一个中文字都没有；中文模式下层名、区域名英文中文都有。
- [ ] 选一首歌下潜：转场中间的曲绘圆正好是地图上的洞放大而成，没有跳一下；署名是 音乐 / 谱师 / 曲绘（英文 MUSIC / CHART / ILLUSTRATION）。

### 7.4 下潜（游戏画面）

- [ ] 开场：3 秒倒计时时只有判定线、轨道和四角，接着 0.3 秒空白，然后音符从屏幕边缘落进来。
- [ ] 写了轨道数的谱（`laneCount`，谱面版本 2.0 起的谱都是）默认带一点 3D：柱子的正面就是平常的画面，还看得到柱子往后的侧面和键的厚度（上半屏看到键的底面，下半屏看到顶面）；谱面转视角时柱子、海面和键跟着转。旧的 8 轨谱照旧是平面的。
- [ ] 整列判定：点音符所在的那一列，上下哪里都算；3D 里按在哪几条轨道在屏幕上占的地方就判这几条轨道的键，交叉处同一拍一个天键一个地键也一起判；同一条轨道天地同拍按一下两个都判。水雷只在本线判定区里、按下的那一刻才算。谱面标了全屏判定的段落：开始前 1 拍两个箭头向外分开，结束前 1 拍两个箭头向内合拢，段落里按屏幕哪里都判最早的键。
- [ ] 两条判定线在 1920 × 1200 画面的 y 1080 和 120（16:10 时离上下边 120）；判定区从线往外 0.4 屏高，上面有一层淡淡的颜色，深浅跟着「判定区提示」拖动条（默认 50%，拖到 0 就没有）。
- [ ] 左上角只有分数（显示成负数；碰到水雷往 0 靠近 10,000，开头还没得分时碰到会变成正数）：在屏幕顶边和上判定线之间按 0.3 / 0.4 / 0.3 放（上空 0.3、字高 0.4、下空 0.3），离左边的距离在电脑、手机和平板上都一样；FC/AR 指示开着时全共鸣淡蓝、出过回响紫色、断了连击白色。
- [ ] 右上角暂停键在同一段的中间，默认双击暂停；左下角难度标签和歌名、右下角剩余时间在同一行；顶上的进度条约屏幕高度的 1%。
- [ ] 屏幕中间是连击数；自动播放时连击数下面写淡绿色的 AUTOPLAY。
- [ ] 暂停：双击暂停键或按 Esc → 暂停菜单（RETRY / RESUME / QUIT，中文 重开 / 继续 / 退出，只显示当前语言）→ 继续时 3-2-1 倒计时，共 3 秒，每个数字 1 秒（和开场一样），倒计时期间音符不动，也不判定。
- [ ] 暂停后按继续（电脑和手机都一样）：3 出现时谱面（轨道、判定线、音符和定住的击打圈）几乎看不见（原来的 0.05 倍），3、2、1 的过程中匀速变回原样，数完正好恢复。
- [ ] 手机上暂停后按继续：倒数时画面定住（3、2、1 每个 1 秒），倒数时听不到音乐，数完音乐马上以原来的音量响起，和音符对得上，不会先停一下或跳一下。连续暂停、继续几次也一样；倒数时再暂停回到暂停菜单。
- [ ] 判定字 RESONANCE / ECHO / LOST、COMBO、EARLY / LATE 和结束横幅 CLEAR / FULL COMBO / ALL RESONANCE 在中文模式下也是英文。
- [ ] 宽屏手机和平板：轨道和判定线撑满整个屏幕，四角贴着角，大小不变。
- [ ] 3D 视角里打击特效是同心球壳和小球，视角怎么转都是正圆；比 240 宽的键，特效按键宽放大（最多 4 倍）。
- [ ] 浪花、潮汐打中时还是那种光带（从判定线浮起、散开，水退回，短暂变暗），但只在跨的那几条轨道上，每条轨道一段，轨道之间的空隙不亮；3D 里是贴着那条轨道柱子的立体光带，转过的轨道也跟着。潮汐按住时的那层水和往上飘的细光带也只在跨的轨道里；漏掉时跨的每条轨道各自闪红。
- [ ] 3D 里潮汐、潮汐水雷的身体是那条轨道柱子里的一个盒子：正面的纹理（由深到浅的填充、两边的亮边、往判定线流的细线）也画在看得见的侧面上（背面只有从柱子后面看才看得见），颜色比 2D 稍重一点；转过、挪过的轨道上身体和头一起跟着轨道。
- [ ] 开着 设置 → 游玩 → 显示触控：每个按着的手指下面有白圈和小点，松开后放大淡出。
- [ ] 谱面里有漩涡（`veils`）时：圆形是一圈圈往外漂的同心圆，多边形是光网，平常一直在晃；在漩涡里按下的手指抬起前打不到任何音符，也不断连击，手指下面有一个和键一样宽的 glitch 触点（不管开没开显示触控），滑出漩涡也跟着；判定线、连击数和判定字在水面上看得清。
- [ ] 谱面里有 DRAG（淡紫色细横条加白边菱形）时：它在自己那条轨道上，跟着轨道动（海面上的按横坐标，写了 `xEvents` 的会左右滑）；手指提前放在它那里、滑过去、按下去都算，到点就是 RESONANCE，手指不在就是 LOST，没有 ECHO；按着长条的手指也能接住；提前接住时打击音到点才响；多押时只轻微变亮。
- [ ] 安卓 10 以上：游玩时从屏幕左右边缘划进来不会触发返回，按住的长条也不断；暂停菜单打开时划返回 = 继续。

### 7.5 结算

- [ ] 左上角是和地图一样的深度徽章（小一些），名字条默认展开，点头像收起。深度加深的一局：徽章右边浮出一个小六边形框写着 ▼ 加深的米数，数字滚到新深度，徽章跟着放大，落地后换成新一档的样子，约 2.5 秒；然后右上角贝壳左边浮出 +N 的贝壳泡，融进贝壳里，数字再加上去（珍珠在最右，贝壳在它左边）。动画中途点一下屏幕会快进到最后。
- [ ] 评级印章（这一局全连是紫色）、NEW BEST 和分数在曲绘左下；点分数弹出明细（准度分 / 共鸣链 / 完美共鸣 / 总计），点贝壳弹出这次的贝壳细则。
- [ ] 偏早或偏晚时下面写「你打得偏晚（+31 ms） · 调整」，点了弹出谱面延时的确认框（取消 / 校准 / 应用）；教程打完写「下一步 · 在地图上选一首歌」。
- [ ] 按钮 重开 / 继续（教程是 再玩一次 / 继续），继续回到地图，卡片上记下了成绩。
- [ ] 手机（比 16:8.5 宽的屏幕）分三栏：左边曲绘和分数，中间连击、早晚和判定数，右边留给人物，按钮在右下角。

### 7.6 设置

- [ ] 左边四项：音频、视觉、游玩、其他（AUDIO / VISUAL / GAMEPLAY / OTHER）。电脑和平板上每页都不用滚动。
- [ ] 音频：谱面延时（滑条、–10 / –1 / +1 / +10 和左边的「校准…」）、音频预设、音乐音量、打击音效音量、界面音效音量（还没有界面音效，所以是灰的）；几行平分整页的高度。
- [ ] 视觉：目押校准（默认 0 px：判定线横穿按键中间）、游戏界面（调整…）、减少动态、背景细节、背景亮度、界面缩放、额外边距、显示帧率。
- [ ] 游戏界面（单独一个画面，左上角返回）：中间是实时预览，一局 12 组（单、单、双），分数开局淡蓝、第 5 组变紫、第 9 组变白；下面是判定字样；左列 背景亮度、故障效果强度、减少闪烁、粒子质量，右列 按键缩放、多押辅助、判定位置、FC/AR 指示、判定区提示（拖动条，0 不显示、默认 50% 和以前「开」一样、100% 更明显）。改了马上在预览里看到。
- [ ] 游玩：过早 / 过晚提示（共鸣、回响两个按钮可以多选）、显示毫秒、偏差条、暂停方式、显示触控、震动。
- [ ] 其他：语言、备份存档、重置记录、新手教程、开源许可证；最下面一行左边大字 K & K，右边 `版本 0.2.0` / `VERSION 0.2.0`。
- [ ] 重置记录：按住 2 秒 → 确认框 → 一字不差地输入玩家名，才能点「重置」；点框外、返回或取消什么都不改。**建议先新建一个测试玩家来试**，或者先用备份存档导出。
- [ ] 开源许可证：K & K 自己的 MIT 许可证、每首歌的曲师 / 谱师 / 曲绘、字体和开源软件；点 查看 看全文，全文左对齐。
- [ ] 延迟校准（音频 → 校准…）和目押校准（视觉 → 校准…）和首次设置里的一样，结果按钮写「应用」；延迟校准测完点「验证」，判定字是 RESONANCE / ECHO / LOST。
